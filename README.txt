# Rohid VIP Portfolio — Fixed Files

Files:
- index.html
- style.css
- script.js

## How to use
1. Extract this ZIP.
2. Keep all three files in the same folder.
3. Keep your profile image at `photo/kk.png` (create a `photo` folder if needed).
4. Open `index.html` in your browser to test.
5. To publish with GitHub Pages, upload these files and the `photo` folder to the repository root.

The JavaScript passed `node --check`.
Update social profile URLs inside `script.js` before publishing if you want those icons to open your real accounts.
